# LZW-архиватор

## Краткое описание
**LZW-архиватор** — CLI приложение, способное архивировать и распаковывать файлы без искажения исходных данных с помощью алгоритма LZW (wikipedia гласит, что Алгори́тм Ле́мпеля — Зи́ва — Уэлча (Lempel-Ziv-Welch, LZW) — это универсальный алгоритм сжатия данных без потерь, созданный Авраамом Лемпелем, Яаковом Зивом и Терри Велчем.)

## Список команд и детали реализации
Команда для работы архиватора в общем виде выглядит следующим образом:

```script.py [-h] [-decoding-d] file_path```

#### Позиционные аргументы:
* file_path - абсолютный или относительный путь к исходному файлу

#### Опциональные аргументы:
* -h, --help - список допустимых команд и справочная информация
* -decoding-d - включение режима декодирования (распаковки)

Данная реализация алгоритма способна сжимать файлы в ~2 раза (_в зависимости от природы исходных данных_)
